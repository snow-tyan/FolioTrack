# FolioTrack 个人资产管理系统

FolioTrack 是一个专为个人设计的现代化、可视化资产管理系统。支持对**中国A股、中国基金、香港港股、美国美股**等多个市场标的进行统一管理与持仓追踪。

系统采用前后端分离架构，前端基于 **Vue 3** 展现精致暗黑风与毛玻璃质感，后端基于 **Go (Gin + GORM)** 提供高性能数据服务，并支持 **Docker Compose** 一键本地化部署。

---

## 🚀 项目特性

- **多市场支持**：统一管理 A股、基金、港股、美股持仓，全自动获取证券名称与实时行情价格。
- **持仓云图（矩形树图）**：基于 Apache ECharts，直观展示持仓总值占比，支持按**“市场分组”**和**“组合分组”**切换，方块颜色按盈亏表现进行 Finviz 式深浅渐变。
- **组合管理**：支持自定义投资组合（如“科技板块”、“红利股”），同一持仓标的可以归入多个组合中。
- **数据导入与导出**：提供标准的 CSV 数据模板，支持一键导出数据备份或将备份 CSV 数据拖拽导入。
- **用户管理与安全**：基于 JWT 认证的多用户独立系统，支持注册与登录。
- **自定义视觉偏好**：支持在顶部导航切换**“红涨绿跌”**与**“绿涨红跌”**，适配国内与海外交易看盘习惯。

## 🛠 一键部署指南

运行本项目最简单快捷的方式是使用 **Docker Compose**：

1. **进入部署目录**：
   ```bash
   cd deploy
   ```

2. **启动服务**：
   ```bash
   docker-compose up -d --build
   ```

3. **访问系统**：
   - 浏览器打开：`http://localhost` 即可进入系统。
   - 默认会自动运行初始化数据库并注册用户，您可以直接点击**“立即注册”**来创建您自己的私有账户。

## 📊 行情接口声明
后台行情数据自动抓取自新浪财经与东方财富的公开非商业化 API 接口，每分钟在后台进行一轮热缓存更新，本地运行请确保服务所在的容器具备公网访问能力。
